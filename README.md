# Yacht Importer

WordPress plugin that imports YachtWorld boat listings into WordPress.

Version 1.5.0 does not require an activation key and does not contact `yachts.wpharbor.com`. Each site still needs its own Boats API key and API URL, configured under Settings → Yacht Importer.

Install by copying this directory to `wp-content/plugins/yachtsboatsapi` and activating **Yacht Importer**.
